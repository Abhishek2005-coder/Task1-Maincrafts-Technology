# 🎓 Student Performance Data Analysis

## 📌 Project Overview

This project analyzes the **Student Performance Dataset** using Python and common Data Science libraries. It performs data cleaning, statistical analysis, and visualization to understand factors affecting students' academic performance.

The project was developed as part of a **Data Science Internship Task**.

---

# 📂 Dataset

**Dataset Name:** Student Performance Dataset

**File:**
```
student-mat.csv
```

The dataset contains information about students including:

- Gender
- Age
- Study Time
- Absences
- Family Support
- School Information
- Final Grade (G3)

---

# 🎯 Objectives

The project performs the following tasks:

- Load the dataset
- Explore the dataset
- Check missing values
- Remove duplicate records
- Calculate average final grades
- Count students scoring above 15
- Analyze correlation between study time and grades
- Compare academic performance by gender
- Create visualizations
- Summarize findings

---

# 📊 Visualizations

The project generates the following charts:

### Histogram
- Distribution of Final Grades (G3)

### Scatter Plot
- Study Time vs Final Grade

### Bar Chart
- Average Final Grade by Gender

### Box Plot
- Grade Distribution by Gender

The dashboard is automatically saved as:

```
student_analysis_dashboard.png
```

---

# 📈 Analysis Performed

The project answers the following questions:

1. What is the average final grade?
2. How many students scored above 15?
3. Is study time correlated with performance?
4. Which gender performs better on average?
